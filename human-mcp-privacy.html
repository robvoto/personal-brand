Human MCP Privacy Policy

Last updated: 24 August 2026

Human MCP is a personal local integration operated by Rob Voto. It lets authorised AI tools access approved local resources and, when explicitly requested, read information from Rob's Gmail account.

Google data accessed

Human MCP requests the Google OAuth scope https://www.googleapis.com/auth/gmail.readonly. This permits read-only access to Gmail messages, threads, headers, body text and attachment metadata needed for user-requested searches and summaries.

Human MCP does not use Gmail permission to send messages, create drafts, delete mail, change labels or otherwise modify mailbox state.

How Google user data is used

Google user data is accessed only when Rob asks an authorised AI client to perform a task that requires Gmail information, such as finding an email, checking a date or summarising correspondence. The requested content may pass through the MCP connection to that authorised AI service so it can answer the request.

Human MCP does not sell Google user data, use it for advertising, or maintain a separate cloud copy of the mailbox.

Storage and security

Google OAuth client credentials and refresh tokens used by Human MCP are stored locally on Rob's computer and are excluded from source control. Human MCP is designed for Rob's personal use and is not offered as a public multi-user Gmail service.

Sharing

Human MCP does not independently share Gmail data with third parties. Data is provided only to the authorised AI client involved in the user-requested task and subject to that service's applicable privacy terms.

Revoking access

Rob can revoke Human MCP's Google access at any time through Google Account security settings or by deleting the locally stored OAuth token.

Google API Limited Use

Human MCP's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions about this integration can be sent to contact@robvoto.com.
